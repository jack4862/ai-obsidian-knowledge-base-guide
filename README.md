# AI + Obsidian 通用知识库构建指南

一份可重复使用的中文知识库构建模板，适用于将书籍、课程、研究资料、工作文档、访谈、项目记录或个人笔记转化为持续维护的 Obsidian Markdown 知识库。

该指南同时面向人与 AI：人负责来源选择、目标设定和价值判断，AI 负责结构化编译、查重、交叉引用、冲突记录、质量巡检和版本维护。

## 开始阅读

[打开完整指南](./AI+Obsidian知识库构建指南.md)

完整指南涵盖：

- 原始资料、编译知识、规则系统三层架构
- 通用目录、页面类型、YAML 属性与文件命名规范
- 概念、来源、方法、比较、问题、项目和决策页面模板
- 新资料摄取、查重、冲突处理与查询回写流程
- 可直接交给 AI 的初始化、摄取、查询和巡检指令
- 质量门槛、维护节奏、Git 跨设备同步与备份
- 学习、研究、工作、团队、代码、个人成长等场景适配

## 使用方式

1. 下载或克隆本仓库。
2. 将 `AI+Obsidian知识库构建指南.md` 复制到任意 Obsidian vault。
3. 让 AI 先完整阅读指南，再根据当前知识库状态提出最小实施计划。
4. 从一份代表性来源开始，先验证完整摄取闭环，再逐步扩展。

指南中的模板、字段和提示词均可按实际领域调整。

## 仓库说明

- 核心内容是普通 Markdown，不依赖特定 AI 服务或 Obsidian 社区插件。
- 原始资料与编译知识分层管理，避免把附件仓库误当成知识库。
- 默认建议使用 Git 保存版本历史，并排除本机工作区状态和缓存。
- 医疗、法律、财务、隐私和版权相关内容应结合人工复核与访问控制。
